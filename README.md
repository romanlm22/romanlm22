## 🚀 Proyectos destacados

### 🌱 AgroManager — Sistema de gestión agrícola y ganadera

Sistema de gestión Full Stack orientado al sector agropecuario, que integra funcionalidades para la administración de actividades agrícolas y ganaderas. El proyecto busca centralizar la gestión de información y facilitar la organización de las operaciones del establecimiento.

**Tecnologías:** Java 21, Spring Boot, PostgreSQL, React, TypeScript y Docker.

**Estado:** ✅ Finalizado.

**Áreas de gestión:** Agricultura y ganadería.

### 🎮 Dungeon Survival — Videojuego 2D

Videojuego de acción y supervivencia desarrollado en C++17, ambientado en una mazmorra medieval. Incluye movimiento del jugador, combate con espada, enemigos que persiguen al personaje, oleadas progresivas y un sistema de puntuación.

**Tecnologías:** C++17, SFML 3 y CMake.

**Conceptos aplicados:** programación orientada a objetos, lógica de videojuegos, detección de colisiones y gestión del tiempo de ejecución.

### 🕹️ GameFinder — Sistema experto de recomendación de videojuegos

Aplicación de consola desarrollada en Common Lisp que recomienda videojuegos según las preferencias del usuario. Implementa un cuestionario interactivo, filtros obligatorios, un sistema de puntuación de compatibilidad, búsqueda por nombre, estadísticas y pruebas automatizadas.

**Tecnologías:** Common Lisp y SBCL.

**Conceptos aplicados:** funciones, estructuras de datos, recursividad, funciones de orden superior, programación funcional y diseño modular.

### 💊 Farmacia Online

Aplicación web de comercio electrónico desarrollada con Laravel, orientada a la gestión y presentación de productos farmacéuticos. Incluye una interfaz de navegación, productos y funcionalidades de carrito de compras.

**Tecnologías:** Laravel, PHP, JavaScript y Bootstrap.

### 📚 Sistema de Gestión de Biblioteca

Aplicación de escritorio desarrollada en Java para administrar libros, ejemplares, socios y préstamos. Incluye persistencia con SQLite, interfaz gráfica con Java Swing e integración con APIs externas para buscar e importar libros.

**Tecnologías:** Java, Java Swing, SQLite, JDBC, Gson, OpenLibrary API y Gutendex API.

### 🗃️ Sistema de Gestión de Ventas — Proyecto académico

Proyecto de bases de datos orientado a la gestión de ventas de un supermercado. Incluye el diseño de un modelo relacional, normalización y desarrollo de scripts SQL para implementar la estructura de la base de datos.

**Tecnologías:** SQL Server y SQL.
